# Narrator

A local, self-hosted text-to-speech narration tool for D&D sessions DM'd via Claude.

Claude writes story narration in chat. This tool reads it aloud using a locally-run
open-source TTS model — no cloud API costs, no microphone input required, no per-character
billing at scale.

See [`docs/PHASE_1_TESTING.md`](docs/PHASE_1_TESTING.md) for the current phase: a local
test harness to compare TTS model quality/speed before any app gets built.

See [`docs/SPEC.md`](docs/SPEC.md) for the full project spec and open questions.
